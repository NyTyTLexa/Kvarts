# Задание на курсовую работу

Реализовать проект «Распределённая информационная система автоматизации закупочных процессов и интеллектуального подбора оборудования». Программный продукт предназначен для подразделения, которое выполняет проекты с проектированием и поставкой оборудования; заказчик внутренний. Исходные требования зафиксированы в техническом задании версии 1.0 от 24.04.2026.

В ходе реализации проекта необходимо:

Выполнить бизнес-анализ предметной области, включая:

- интервьюирование заказчика;
- анкетирование конечных пользователей;
- описание заинтересованных лиц и конечных пользователей;
- словарь предметной области;
- анализ бизнес-требований (в виде схемы бизнес-целей, бизнес-требований и функций системы).

Провести сравнительный анализ существующих аналогичных решений на рынке.

Разработать концепцию решения, включая:

- описание общей функциональности решения;
- детализацию требований к решению (пользовательские истории с учётом приоритетов и декомпозиции по методике User Story Mapping);
- описание границ решения;
- описание возможных архитектурных и технических решений.

Спроектировать разрабатываемую систему, включая:

- проектирование архитектуры и структуры системы;
- проектирование базы данных;
- прототипирование интерфейса пользователя;
- детальное проектирование отдельных модулей при необходимости.

Выполнить программную реализацию первой версии системы (продукта).

Выполнить функциональное тестирование системы по тестовым сценариям.
