# Интерфейс живого стенда

Это **актуальный** вид SPA (`frontend/`, http://localhost:5173), а не макет.
Прототип [design_handoff_kvarts/](design_handoff_kvarts/) («Кварц») — состав экранов B1–B21.
Живой скин — **кабинет снабженца**: серый стол `#e8edf2`, белая таблица, сайдбар
`#243447`, акцент `#1b6aa3`, PT Sans 13.5. Журнал документов, не лендинг и не
панель деплоя. Эмодзи нет.

Отклонено (не возвращать без новой записи): крем Notion, сталь+жёлтый «щит»,
Oswald/конструктивизм, Vercel Geist/чёрный hero, зелёные обои «Rennale».

Код токенов: `frontend/src/styles/tokens.css`. Меню: `frontend/src/auth/access.ts`.
Каркас: `frontend/src/components/Shell.tsx`, `PageHead.tsx`.

Если снова меняется палитра, сетка меню или принцип подписей — править **этот файл
в том же ходе**, что и CSS. Не оставлять расхождение «в чате».

## 2. Односложные вкладки

Пункты меню нарочно короткие («Прайсы», «Склад», «Маржа»). Одно слово на чёрном
сайдбаре без пояснения выглядит пустым ярлыком.

Правило: **короткое имя + вторая строка, зачем раздел**.

```
Заявки
перечень → КП
```

На странице то же самое кикером над заголовком: `04 · перечень → КП` / **Заявки**.
Не раздувать пункт до «Загрузка спецификации заказчика».

| Пункт | Подпись (hint / kicker) | Экран |
|---|---|---|
| Проекты | 01 · тендеры | `/` |
| Карточка проекта | 01 · карточка проекта | `/projects/:id` |
| Прайсы | 02 · excel поставщиков | `/prices` |
| Каталог | 03 · цены в витрине | `/ecatalog` |
| Заявки | 04 · перечень → КП | `/specifications` |
| Сопоставление | 04 · разбор строк | `/specifications/:id/match` |
| Четыре КП | 04 · листы КП | `/specifications/:id/quote` |
| Заказы | 05 · снимок КП | `/orders` |
| Маржа | согласование · комблок | `/approval` |
| Счета | согласование · NOC | `/invoice` |
| Склад | согласование · приёмка | `/warehouse` |

Четвёртый вариант КП в UI называется **«Актуальность»**, не «ML» (на защите «ML» без
контекста не читается). Алгоритм тот же, см. [ML_MATCHING.md](ML_MATCHING.md).

Группа меню **«Контур КП»** — сквозной сценарий, не «Работа / Закупки»:
проекты → прайсы → каталог → заявки → заказы.

## Темы цвета

Атрибут `data-theme` на `<html>`, выбор в `localStorage` (`ps-theme`). Цвета статусов,
чипов поставщика и кнопок идут из токенов (`--ok-fg`, `--info-fg`, `--on-accent`) —
иначе «Ночь» и «Склад» ломаются зашитым синим Tailwind.

Переключатель: **имя текущей темы** в шапке (все роли) и карточки в **Настройки**.
Так устроены цветовые схемы B2B-порталов, не «четыре точки в Figma».

| id | Имя | Акцент | Зачем |
|---|---|---|---|
| `cabinet` | Кабинет | `#1b6aa3` | по умолчанию |
| `graphite` | Графит | `#4a5c6c` | нейтральный стол |
| `forest` | Склад | `#2d6a4f` | учёт / приёмка |
| `night` | Ночь | `#4aa3d4` | тёмная смена |

## Телефон

Это не сжатый десктоп, а **отдельный каркас** ≤860px.

- Нижние вкладки по роли (РП: Проекты / Заявки / Каталог / Маржа; КБ стартует с Маржи). **Ещё** открывает то же меню, что сайдбар.
- Кнопки экрана («Передать в КБ», Excel) — полоса над вкладками, не в шапке.
- Шапка: название экрана, тема, колокол.
- Журналы скроллятся внутри листа. Четыре КП — столбиком.
- Vite слушает сеть (`--host`): с телефона в той же Wi‑Fi открывать адрес **Network**, не `localhost`.
- Манифест: Safari → Поделиться → На экран «Домой». Вход формой логина, не OIDC-редиректом.

Десктоп (≥861px) без изменений: сайдбар 232px, шапка в один ряд.

## 3. Кадры для защиты (2–3 минуты)

Не начинать со справочников и номенклатуры — это рабочие таблицы.

1. Жёсткое обновление вкладки (`Ctrl+F5`), чтобы подтянуть PT Sans.
2. Вход `manager` / `manager`. Форма «Вход в кабинет».
3. В шапке тема: Кабинет / Графит / Склад / Ночь.
4. **Проекты** — журнал (дата, статус, сумма, маржа).
5. Клик по строке — **развёрнутый проект** (lifecycle, четыре листа, финансы).
6. **Сопоставление** → **Четыре КП**. Стоп на «Актуальность».
7. По времени: **Маржа** (комблок).

Роли стенда (пароль = логин): `manager`, `commercial`, `accounting`, `warehouse`, `admin`, `viewer`.

## 4. Что совпадает с макетом Кварц

Экраны и сценарии те же: B1 проекты, B20 карточка проекта, B2 прайс, B3 сравнение КП, B4 детальный КП,
B6 комблок, B7 счёт, B11 склад, B16 сопоставление. Компоненты: `Btn`, `StatusPill`,
`LifecycleBar`, сайдбар + шапка. RBAC как в ТЗ.

Расходится **материал** (цвет, шрифт, плотность кадра), не состав функций.
Для главы пояснительной «Интерфейс»: скриншоты **со стенда**, макет Кварц — как
исходный прототип и обоснование состава экранов.
