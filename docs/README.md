## Что ещё нужно для пояснительной (этап 11)

Черновик собран: главы в [zapiska/src/](zapiska/src/), пересборка

```bash
python docs/zapiska/build_docx.py
```

пишет `docs/zapiska/Пояснительная_записка.docx`. Lock-файл Word `~$…docx` не трогать.

Руками остаются:

- поля титула (факультет, кафедра, дисциплина, ФИО);
- скриншоты экранов под главу «Интерфейс»;
- блок-схемы процесса «для печати» (Visio / вставка из mermaid ARCHITECTURE.md).

## Правило актуальности

Если меняется поведение, которое фигурирует в ТЗ (новый экран, новый статус, новая интеграция) —
сначала код, сразу после — строка в [TZ_COVERAGE.md](TZ_COVERAGE.md) и, при необходимости,
эндпоинт в [API.md](API.md). README-дорожная карта не должна противоречить сверке.

Кардинальная смена вида (палитра, сетка меню, принцип подписей, кадр защиты) —
в том же ходе запись в [UI.md](UI.md). Макет «Кварц» сам по себе не обновлять: это
зафиксированный прототип.
